Efficient Transformers Library¶

Train anywhere, Infer on Qualcomm Cloud AI with a Developer-centric Toolchain

QEfficient (QEfficient) is the library interface for Hugging Face Transformer models for efficient inference on Qualcomm Cloud AI 100.

Overview¶

The library provides:

  1. Reimplemented LLM blocks — optimized for on-device retention of intermediate states
  2. Graph transformations — lower-precision execution, mathematically equivalent op replacements
  3. Underflow/overflow handling — safe lower-precision computation
  4. Weight patching — maps original model weights to updated model operations
  5. ONNX export — exports model source to an ONNX graph
  6. Example applications — tutorials, demo notebooks, CLI scripts
  7. Unit test templates — reproducible quality gates

Quick Install¶

# Create Python virtual env (Python 3.12 recommended)
python3.12 -m venv qeff_env
source qeff_env/bin/activate

pip install QEfficient

Or from source:

git clone https://github.com/quic/efficient-transformers
cd efficient-transformers
pip install -e .

Quick Example¶

from QEfficient import QEFFAutoModelForCausalLM
from transformers import AutoTokenizer

model_name = "Qwen/Qwen2-1.5B-Instruct"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = QEFFAutoModelForCausalLM.from_pretrained(model_name)

# Compile for Cloud AI 100
model.compile(prefill_seq_len=32, ctx_len=128, num_cores=16)

# Generate
output = model.generate(
    tokenizer=tokenizer,
    prompts=["What is Qualcomm Cloud AI 100?"],
)
print(output.generated_texts[0])
