Supported Features¶

Feature Impact
Diffusion Models Full support for diffuser-based image generation models like Stable Diffusion, Imagen, Videogen enabling efficient image and video synthesis tasks.
Disaggregated Serving for GPT-OSS Enabled for GPT-OSS models, allowing for flexible deployment of large language models across different hardware configurations.
ONNX Sub-Functions Feature enabling more efficient model compilation and execution on hardware.
BlockedKV attention in CausalLM Implements a blocked K/V cache layout so attention reads/processes the cache block-by-block, improving long-context decode performance.
Compute Context Length (CCL) Optimizes inference by using different context lengths during prefill and decode phases, reducing memory footprint and computation for shorter sequences while maintaining support for longer contexts. Supports both text-only and vision-language models. See sample script.
Sentence Embedding, Flexible Pooling, Multi-Sequence-Length Compilation Supports standard/custom pooling with AI 100 acceleration and sentence embedding. Enables efficient sentence embeddings via Efficient-Transformers. Compile with one or multiple seq_len; optimal graph auto-selected at runtime. See sample script.
SpD, Multiprojection Heads Implemented post-attention hidden size projections to speculate tokens ahead of the base model. See sample script.
QNN Compilation Support Enabled for AutoModel classes QNN compilation capabilities for multi-models, embedding models and causal models.
Disaggregated Serving Supports separate prefill and decode compilation for encoder (vision) and language models.
GGUF Model Execution GGUF model execution (without quantized weights). See sample script.
Replication of KV Enabled FP8 model support on replicate_kv_heads script.
Gradient Checkpointing Supports gradient checkpointing in the finetuning script.
SwiftKV — Snowflake/Llama-3.1-SwiftKV-8B-Instruct Reduces computational overhead during inference by optimizing key-value pair processing, improving throughput. Supports both continuous and non-continuous batching.
Vision Language Model Provides support for the AutoModelForImageTextToText class, enabling advanced vision-language tasks. See sample script.
Speech Sequence to Sequence Model Provides support for QEFFAutoModelForSpeechSeq2Seq, facilitating speech-to-text sequence models. See sample script.
FP8 Execution Enables execution with FP8 precision, significantly improving performance and reducing memory usage.
Prefill Caching Enhances inference speed by caching key-value pairs for shared prefixes, reducing redundant computations.
On Device Sampling Enables sampling operations directly on the QAIC device, reducing host-device communication overhead and improving throughput. See sample script.
Prompt-Lookup Decoding Speeds up text generation by using overlapping parts of the input prompt and generated text. See sample script.
PEFT LoRA Support Enables parameter-efficient fine-tuning using low-rank adaptation, reducing computational and memory requirements. See sample script.
QNN Support Enables compilation using QNN SDK, making Qeff adaptable for various backends.
Embedding Model Support Facilitates the generation of vector embeddings for retrieval tasks.
Speculative Decoding Accelerates text generation using a draft model, reducing latency and improving efficiency. See sample script.
Finite LoRAx — Multi-Adapter Users can activate multiple LoRA adapters compiled with the base model. At runtime, specify which prompt uses which adapter for mixed adapter batches. See sample script.
Python and CPP Inferencing API Provides flexibility for inference with Qeff, enabling integration with various applications. See sample script.
Continuous Batching Optimizes throughput and latency by dynamically batching requests.
AWQ and GPTQ Support Supports advanced quantization techniques, improving model efficiency and performance on AI 100.
Successive Session Requests An API that yields tokens as they are generated, facilitating seamless integration with various applications.
Perplexity Calculation A script for computing model perplexity for evaluation and comparison. See sample script.
KV Heads Replication Script A sample script for replicating KV heads for LLaMA-3-8B-Instruct, validating changes, and exporting to ONNX. See sample script.
